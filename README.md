# Telegram-бот "Гидрататор"

Учебный проект. Бот для мессенджера Telegram для учёта потребления воды.

### Требования к проекту:
- Добавлять объём выпитой воды к общему учёту;
- Выводить информацию о выпитой воде в сутки пользователю индивидуально;
- Иметь возможность спросить объём выпитой воды за сутки;
- Если объём выпитой воды больше дневной нормы, поздравлять пользователя при выводе статистики;
- Реализовать все функции через клавиатуру ReplyKeyboardMarkup;
- Отображать клавиатуру после отправки пользователем сообщения `/start`;
- Использовать библиотеку aiogram 3.x;
- Хранить данные во временном словаре памяти Python. 

## Реализация
### Данные пользователя хранятся в переменной `DATA` в виде вложенного словаря. Словарь имеет следующую структуру:
```text
DATA
└── (id пользователя, тип данных int) : {...}
                                        ├── 'date': (дата последнего сообщения о выпитой воде, тип данный str)
                                        └── 'water': (общее кол-во выпитой воды за сутки, тип данных int)
```
В общем словаре по ключам из id пользователей возвращается значения в виде другого словаря с ключами `'date'` возвращающим значения даты последнего сообщения о выпитой воде и `'water'` возвращающим  количество выпитой воды за сутки.

### Функции для регистрации и проверки пользователя:
- `register_user` - осуществляет ленивую регистрацию. Если id пользователя есть в `DATA`, то возвращает его данные. Если его данных нет, то вставляет пустой шаблон и возвращает его. Шаблон:
```python
{
    'date': 'XX-XX-XXXX', #дата сообщения от пользователя
    'water': 0 #кол-во выпитой воды
}
```
- `check_user` - функция проверяет есть ли id пользователя в словаре `DATA` и возвращает `True` или `False`. Функция используется для определения ответа пользователю на его сообщения;
- `check_user_exception` - данная функция построена на функции `check_user`. Она позволяет вызвать исключение SkipHandler,чтобы пропустить данный хендлер и отправить сообщения на обработку другим хендлерам.

### Функции для учёта воды:
- `func_add_water` - функция получает данные пользователя из `DATA`, проверяет дату последнего учтёного ботом выпитого стакана воды `user['date']` и если эта дата соответствует сообщению о новом выпитом стакане (что вызывает эту функцию), то добавляет к общему суточному объему `user['water']` новый стакан, если последний стакан был выпит не сегодня, то устанавливает `user['water']` в объем стакана и обновляет дату `user['date']` на дату сообщения, что вызвало эту функцию;
- `func_statistics` - функция получает данные пользователя из `DATA`, сравнивает дату `user['date']` с датой сообщения вызова функции, в случае совпадения возвращает количество выпитой воды `user['water']`, при расхождении возвращает 0;
- `func_reset` - функция получает данные пользователя из `DATA` и устанавливает в `user['date']` дату сообщения вызова функции и 0 в `user['water']`.

### Хендлеры:
- `cmd_start` - вызывается сообщением от пользователя с командой `/start`. Регистриует пользователя через `register_user`, отображает клавиатуру для пользователя;
- add_water -  вызывается сообщением от пользователя с текстом "🥤 Выпил стакан (250 мл)". Регистрирует пользователя (если он не был зарегистрирован) через `register_user`, вызывает функцию `func_add_water` и отвечает сообщением с общим количеством выпитой воды;
- `statistics` - вызывается сообщением от пользователя с текстом "📊 Мой прогресс". Проверяет, зарегистрирован ли пользователь через `check_user_exception`. Отправляет пользователю сообщение, если он зарегистрирован, с общим количеством выпитой воды. Если это количество больше дневной нормы, поздравляет пользователя.
- `reset` - вызывается сообщением от пользователя с текстом "🔄 Сброс". Проверяет регистрацию пользователя через `check_user_exception` и сбрасывает количество выпитой воды на 0;
- `fallback` - последний хендлер, обрабатывает все сообщения, что не вызвали другие хендлеры и были пропущены при их выполнении. Проверяет регистрацию пользователя через `check_user`. Затем предлагает пользователю отправить команду /start или в случае его регистрации воспользоваться клавиатурой.
